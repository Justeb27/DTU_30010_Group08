This project focuses on the development and implementation of a computer game that runs on a STM32-microcontroller. The game is written in the programming language C and is inspired by the classic arcade game \textit{Space Invaders}. It focuses on both functionality and achieving an optimal user experience. Additionally, the project utilizes a system architecture that ensures most game components, modules and functions are reusable.
The game features meteors with gravitational pull, eight different shooting angles, power-ups and an LCD-display showing lives and points, and operates smoothly and efficiently. The game is controlled using an external joystick 30010, which allows the player to maneuver the spaceship, shoot, and navigate the menu. 

The project has provided valuable experience in C programming, collaboration during the development process, and software architecture. This report documents the designs, implementations, challenges, and results concluding that the game meets the required specifications and delivers a unique and excellent user experience.
